# Limits of the study and construction

No measured result exists. All source was built in Dirty Mode; dependencies, tests, type checking, builds and the viewer have never run. Syntax checks and source reviews cannot establish runtime correctness. See DEFERRED-VALIDATION.md.

The primary endpoint is defect exposure recall: required changed-line atoms appear in an allocated reading prefix. It does not measure discovery, semantic review quality, maintainability, causal effects or agent versus human performance. There is no composite quality metric. Optional arm B reports localization hits, not discovery; mock output is never measurement.

The proposed corpus has 40 synthetic roots with 20 held-out roots. Synthetic planted defects and selected applicability sites cannot represent arbitrary real agent changes. Root bootstrap uncertainty may be wide; a half-width greater than 15 percentage points is labelled imprecise. No post-result corpus extension is allowed. A null or inconclusive result must remain visible.

Builders wrote product code before the independent corpus existed under Roy's construction authorization. This weakens the original sequence. C1 must be a fresh non-builder session with only the author packet, never the metric/policy implementation. Both Claude and Codex now belong to builder lineage. Builder-authored engineering fixtures and worksheets are not independent study evidence. Gate 1 requires C1's own worksheet and executed witnesses; neither exists yet.

Metrics are syntactic and parse-only. Anonymous functions fold into their named owner; ambiguous maps and parse failures become manual review, counted with tier 2. Unchanged tests are not inspected. Identifier references in changed tests do not prove an assertion. Deleting a guard can lower complexity and evade a growth rule. Defensive code can trigger catches, complexity and clone diagnostics; clean twins and named near-misses expose that cost.

The raw scanner used for trivia/token comparisons has heuristic handling of regular expressions and template continuations. JSX text and slash tokens after closing parentheses need Normal-mode comparison against parser-derived leaves. Class field initializers have attribution limits. Unreachable statements are a direct-successor return/throw diagnostic, not control-flow analysis. The corrected clone scanner enumerates matching partners; repetitive inputs can require quadratic work. Completeness and performance reference scripts are written but unexecuted. Deletion-only catch changes can evade the declared head-atom catch signal. These are validation targets, not claims of equivalence to full semantic tools.

The line diff, parser versions, original byte hashes and normalization rules must match C1's harness. Omission anchors and genuine base deletions follow ATOMS.md; an absent required atom aborts before scoring. Partial hunks charge changed lines only; context is shown without budget cost. Whole-hunk sensitivity is reported separately.

External baseline rows remain not captured until versions, licenses, mappings and source hashes are checked. Lizard remains not captured because its license is unresolved. S41 is an unavailable adapter, never a silent replacement corpus. The optional live reviewer has no adapter; the local ledger defaults to zero spend and disabled live dispatch. USD 40 is only Roy's ceiling, not credential/model/run approval.

The static browser viewer reads generated public JSON only. It has no upload, repository execution, backend, authentication or private-corpus access. Publish only deliberately sanitized artifacts after a separate authorization; this construction run adds no remote and publishes nothing.
